# Home-screen landscape

Layers of "Mountain at Dusk Background" by ansimuz, released under CC0 (public domain):
https://opengameart.org/content/mountain-at-dusk-background

The colours were re-graded from dusk to night for hate-agent, and `sky-moonless.png` is the
sky tile with the moon painted out so the sky can repeat on wide windows without a second moon.
Each tile is 160px tall; the sky and far mountains repeat every 272px, the other layers every 544px.

No attribution is required by the licence; this note is here so the source stays known.
